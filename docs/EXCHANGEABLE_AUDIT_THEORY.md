# Exchangeable corruption-location theory

## 1. Transfer assumption

Within trusted stratum `h`, there are `N_h` records and an unknown fixed corruption count `M_h`. Conditional on `M_h`, the corrupted locations are uniform over all subsets of size `M_h`. This is exchangeability of locations only.

## 2. What remains adversarial

Corrupted values remain arbitrary and may depend on the clean tuple, survival status, censoring status, and observed values. No error magnitude, outcome channel, independence, or unbiasedness assumption is made. Audits reveal `(Y*, Delta*)`, not latent post-censoring `T`.

## 3–4. Trusted strata and audit law

`H` is observed and uncorrupted before audit. Uniform sampling of `b_h` records without replacement gives

`D_h | (M_h,N_h,b_h) ~ Hypergeometric(N_h,M_h,b_h)`.

This is STANDARD finite-population sampling theory, not a new survival result.

## 5. Exact `M_h` confidence set

For observed `D_h=d`, retain `m in {0,...,N_h}` when both finite-population tails satisfy

`P_m(D >= d) >= alpha_h/2` and `P_m(D <= d) >= alpha_h/2`.

The resulting equal-tail inverted set is conservative: exhaustive enumeration gives coverage at least `1-alpha_h`. For `b_h=0`, it is all `m`; for `b_h=N_h`, it is the singleton `{d}`. This is STANDARD exact acceptance/audit certification.

## 6. Simultaneous coverage

Bonferroni with `sum_h alpha_h <= alpha` gives simultaneous coverage at least `1-alpha`. Conditional independence of independently sampled audit subsets permits an exact product calculation, but does not change the basic certification result.

## 7. Post-audit clean-data feasible set

Given an upper endpoint `U_h^M` and discovered discrepancies `D_h`, the remaining unknown corruption count is at most `U_h^M-D_h`. The audited clean tuples are fixed; unverified corrupted values remain adversarial. This is a deterministic finite-population feasible set conditional on the stochastic event that the true `M_h` lies in its confidence set.

## 8. Recorded-event certificate

For binary recorded event status, if `u_1` and `u_0` are unverified observed events and non-events, the sharp conditional interval is

`[(u_1-min(u_1,k))/N_h, (u_1+min(u_0,k))/N_h]`

plus the audited clean-event count divided by `N_h`, where `k=U_h^M-D_h`. Its coverage is inherited from the count confidence set; its width is not a confidence interval generated by treating corrupted values as random.

## 9–10. One-bin survival channel and width

Under the declared one-bin channel `r_h=g_h p_h`, with known `g_h`, `g_h>0`, the certified survival interval is `[max(0,L_r/g_h), min(1,U_r/g_h)]`. If `g_h=0`, `p_h` is not identified by this channel. The width is the recorded certificate width divided by `g_h`, capped at one. This is ELEMENTARY_COMPOSITION.

## 11–12. Clean audit and positive discovery

When `D_h=0`, use the exact upper endpoint `U_h^M(0;b_h,N_h,alpha_h)`. The implementation verifies the worst binary-composition width `min(N_h,2U_h^M)/N_h`, followed by the `1/g_h` cap. A positive `D_h` reduces the remaining budget by the discovered discrepancies but can enlarge the confidence-set upper endpoint; discovery is therefore not uniformly helpful.

## 13. Sample complexity

The implemented `b*` is conditional on the clean-audit outcome `D_h=0`, uses worst observed binary composition, and is the smallest integer audit size whose declared survival width is at most `delta`. It is not a worst-case-over-D or expected sample complexity. Computed tables are in `results/step07/exchangeable_checks.json`.

## 14. Acceptance-sampling reduction test

The one-bin result is exactly standard hypergeometric defect-count certification followed by the known-channel map `r/g`. The kill test therefore returns YES. The result is correct but insufficient as the primary theorem.

## 15–18. Aggregate target, allocation, and global cap

For `p=sum_h pi_h p_h`, independent stratum certificates can be summed after prevalence weighting. Under `sum_h M_h<=m`, remaining corruption budgets are coupled by an integer allocation; the exact tiny-population oracle optimizes event counts over all allocations. This can tighten the interval, but it is still a coupled acceptance-sampling calculation. It does not create a survival-specific theorem.

## 19. Marginal audit value

Exact enumeration supports discrete marginal values, but no general submodularity or greedy-optimality claim is made. A weighted clean-audit allocation can differ from proportional allocation because the objective contains `pi_h/g_h`; that is a direct scalar rescaling effect, not a distinct survival identification phenomenon.

## 20. Adaptive-wave note

A second-wave allocation can change after observed discrepancies, as in ordinary multiwave validation. No adaptive theorem is claimed.

## 21. Two-bin pilot

NOT COMPUTED. The one-bin direction failed the survival-specificity kill test, so a two-horizon extension was not used to rescue the pivot.

## 22. Literature overlap

Exact hypergeometric certification belongs to classical finite-population audit sampling.[4]

Two-phase survival validation optimizes validation designs for estimator precision under measurement-error models.[1]

Multiwave EHR validation uses influence-function information from unvalidated and validated data to allocate validation effort.[2]

Semi-verified learning studies trusted/untrusted data transfer in a broader learning setting.[3]

These sources make the present exchangeable-location result a transfer model and a reproducible baseline, not an established novel theorem.

## 23. Limitations

The channel `r=g p` is a one-bin known-follow-up abstraction, not a general Kaplan–Meier identification result. The confidence set is conservative. E1 has no prior on `M_h`; E2 is only a deterministic global cap. No finite-sample estimation of `g_h`, multi-time censoring structure, or real validation data is included.
