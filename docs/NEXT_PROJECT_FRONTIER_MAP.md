## Dataset access verification

- **SEER:** official data portal, https://seer.cancer.gov/data/. It provides cancer registry data with time-to-event fields and cause/death information; access terms vary by dataset and requires following the official request/download conditions. Treat as public-accessible by application, not as unrestricted anonymous download.
- **MIMIC-IV:** official PhysioNet page, https://physionet.org/content/mimiciv/3.1/. It is credentialed/restricted access, requires a PhysioNet account, training, and data-use agreement. It is not an immediately open dataset.
- **calibmsm example data:** the 2025 paper states that package data and a figshare copy are available; this is a small reproducibility asset, not a broad benchmark. Package/code: https://github.com/alexpate30/calibmsm; figshare link is given in the paper.
- **EBMT example:** available through the `mstate` ecosystem as an example, but not a substitute for an external multi-site benchmark.
- **SUPPORT:** commonly distributed through survival-analysis tooling, but access/licensing and exact endpoint semantics must be rechecked before a future protocol.

No large dataset was downloaded during Step 09. Dataset claims above are access-condition findings from official pages, not executed data-ingestion verification.

## Broad conclusion

The most defensible independent frontier is not another censoring perturbation. The strongest candidates concern **decision-relevant calibration/transport of competing-risk or multi-state predictions**, with a second line on observation-process shortcuts. Every finalist still requires a fresh primary-source and access audit before implementation.
