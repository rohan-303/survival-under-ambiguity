# Q10 Theorem and Benchmark Candidates

| Candidate | Assessment |
|---|---|
| T1 impossibility | Known generic result; useful boundary, not novelty. |
| T2 task-conditioned representation-risk bound | Potentially interesting but threatened by domain-adaptation theory; no distinct bound derived. |
| T3 silent-failure detection | Empirically plausible, but requires held-out temporal labels and comparison with SUDO/uncertainty. |
| B1 temporal clinical-NLP early-warning benchmark | Potentially useful, but Clinical-ShiftEval is a direct overlap threat and no dataset/task contract is yet frozen. |
| B2 controlled semantic perturbation benchmark | Rejected as a novelty route because synthetic shift/explanation work already occupies the design space. |

The strongest candidate is B1 paired with T3, but it remains a hypothesis and not a project authorization. No model, embedding pipeline, or benchmark was built.
